## PROMPT 1: Portfolio Risk Alert
**Zielgruppe:** Risk Manager, Portfolio Manager
**Business Value:** €€€€€ (Verhindert Verluste)

### Der Prompt:
```
"Überwache mein Portfolio und alarmiere mich sofort, wenn:
- Eine Position mehr als 5% an einem Tag verliert
- Die Portfolio-Volatilität über 25% steigt
- Die Korrelation zwischen meinen Top-3-Positionen über 0.8 steigt
- Ein Earnings Report für eine meiner Positionen in den nächsten 7 Tagen ansteht"
```

### Warum wertvoll:
- Proaktiv statt reaktiv
- 24/7 Monitoring ohne menschlichen Aufwand
- Regelbasierte Alerts = Compliance-freundlich

### Was dafür nötig ist:
- [ ] Scheduler/Cron für regelmäßige Checks
- [ ] Push Notifications (Email, Slack, SMS)
- [ ] Korrelationsberechnung
- [ ] Earnings Calendar Integration
- [ ] Persistentes Portfolio-Konzept

## PROMPT 2: Earnings Call Analyse
**Zielgruppe:** Equity Analyst, Portfolio Manager
**Business Value:** €€€€€ (Alpha Generation)

### Der Prompt:
```
"Analysiere den letzten Earnings Call von NVIDIA:
1. Was waren die 3 wichtigsten Aussagen des CEO zu AI-Umsätzen?
2. Wie hat sich der Guidance-Ton vs. letztes Quartal verändert?
3. Welche Fragen der Analysten wurden ausweichend beantwortet?
4. Vergleiche die Aussagen mit der tatsächlichen Aktienperformance der letzten 5 Tage"
```

### Warum wertvoll:
- Earnings Calls sind 60+ Seiten - niemand liest alles
- Sentiment-Shifts sind oft subtil aber wichtig
- Verbindung Narrative ↔ Price Action ist Alpha

### Was dafür nötig ist:
- [ ] RAG System für Dokumente
- [ ] Earnings Call Transkript-Quelle (z.B. Seeking Alpha API)
- [ ] Sentiment Analysis
- [ ] Historischer Vergleich (vorheriger Call)
- [ ] Price Data Integration (hast du!)

## PROMPT 3: Rebalancing Empfehlung
**Zielgruppe:** Portfolio Manager, Wealth Manager
**Business Value:** €€€€ (Risikomanagement)

### Der Prompt:
```
"Mein Portfolio:
- 40% AAPL
- 30% MSFT  
- 20% GOOGL
- 10% Cash

Die Ziel-Allokation ist 25% pro Aktie.
Berechne:
1. Welche Trades sind nötig um zu rebalancen?
2. Was wäre die Volatilitätsänderung nach Rebalancing?
3. Wie hätte das rebalancte Portfolio im letzten Jahr performt vs. aktuell?"
```

### Warum wertvoll:
- Rebalancing ist mechanisch aber zeitaufwendig
- Simulation zeigt Impact bevor man handelt
- Dokumentation für Compliance

### Was dafür nötig ist:
- [ ] Portfolio-Datenmodell (Positionen, Gewichte)
- [ ] Trade-Kalkulation
- [ ] Backtesting-Logik
- [ ] Vergleichsanalyse (hast du teilweise!)

## PROMPT 4: Peer Comparison mit Begründung
**Zielgruppe:** Equity Analyst
**Business Value:** €€€€ (Investment Decisions)

### Der Prompt:
```
"Vergleiche SAP mit seinen direkten Konkurrenten:
1. Identifiziere die 4 relevantesten Peers (nicht ich - DU entscheidest)
2. Vergleiche: Revenue Growth, Margin, P/E, EV/EBITDA
3. Wo ist SAP über-/unterbewertet relativ zu Peers?
4. Was sind potenzielle Gründe für die Bewertungsunterschiede?"
```

### Warum wertvoll:
- Agent muss SELBST Peers identifizieren (nicht vorgegeben)
- Kombiniert Daten + Reasoning
- Ersetzt 2-3 Stunden Analyst-Arbeit

### Was dafür nötig ist:
- [ ] Peer-Identification Logic (Sector, Size, Geography)
- [ ] Fundamentaldaten für alle Peers (hast du!)
- [ ] Bewertungsmetriken
- [ ] LLM Reasoning für Interpretation

## PROMPT 5: Compliance Pre-Check
**Zielgruppe:** Compliance Officer, Portfolio Manager
**Business Value:** €€€€€ (Vermeidet Strafen & Reputationsschäden)

### Der Prompt:
```
"Ich will 10.000 Aktien von Deutsche Bank kaufen.
Prüfe:
1. Würde das unsere Konzentrationslimits verletzen (max 5% pro Position)?
2. Ist Deutsche Bank auf unserer Restricted List?
3. Gibt es offene Blackout-Perioden (Earnings in <14 Tagen)?
4. Wie ist die 30-Tage-Liquidität - können wir 10k Aktien kaufen ohne Market Impact?"
```

### Warum wertvoll:
- Compliance-Verstöße = Millionenstrafen
- Aktuell: Manuelle Checklisten, fehleranfällig
- Automatisierung = schneller + sicherer

### Was dafür nötig ist:
- [ ] Portfolio-Positionen mit Limits
- [ ] Restricted List (interne Daten!)
- [ ] Earnings Calendar
- [ ] Liquiditätsanalyse (Average Volume)
- [ ] Regelengine für Compliance-Checks

## PROMPT 6: Automatischer Morning Brief
**Zielgruppe:** Portfolio Manager, CIO
**Business Value:** €€€€ (Zeitersparnis)

### Der Prompt:
```
"Erstelle meinen täglichen Morning Brief für mein Portfolio (AAPL, MSFT, NVDA, GOOGL, AMZN):
1. Overnight Performance (US Close → EU Open)
2. Wichtigste News pro Position (max 2 Sätze)
3. Anstehende Events diese Woche (Earnings, Ex-Dividende, etc.)
4. Technische Signale (RSI, Moving Average Crossovers)
5. Ungewöhnliche Optionsaktivität wenn verfügbar

Format: Executive Summary in 10 Zeilen, Details darunter"
```

### Warum wertvoll:
- Jeder PM verbringt 30-60 Min morgens mit Recherche
- Automatisierung spart 200+ Stunden/Jahr
- Konsistentes Format = schnelle Verarbeitung

### Was dafür nötig ist:
- [ ] Scheduler (täglich 7:00 Uhr)
- [ ] News API Integration
- [ ] Technische Indikatoren (RSI, MA)
- [ ] Events Calendar
- [ ] Report Generation (PDF/Email)

## PROMPT 7: What-If Szenario Analyse
**Zielgruppe:** Risk Manager, Strategist
**Business Value:** €€€€€ (Entscheidungsunterstützung)

### Der Prompt:
```
"Was passiert mit meinem Portfolio wenn:
Szenario A: Fed erhöht Zinsen um 50bps
Szenario B: China-Taiwan Konflikt eskaliert
Szenario C: Tech-Earnings enttäuschen um durchschnittlich 10%

Für jedes Szenario:
1. Geschätzte Portfolio-Performance (basierend auf historischen Analogien)
2. Welche Position ist am verwundbarsten?
3. Welche Hedging-Optionen hätte ich?"
```

### Warum wertvoll:
- Stress Testing ist regulatorisch gefordert (Basel III)
- Proaktives Risikomanagement
- Board-ready Szenarien

### Was dafür nötig ist:
- [ ] Historische Szenario-Datenbank
- [ ] Sensitivitätsanalyse (Beta zu Faktoren)
- [ ] Hedging-Logik (Optionen, Shorts)
- [ ] Report Generation

## PROMPT 8: Research Synthesis
**Zielgruppe:** Research Analyst, Portfolio Manager
**Business Value:** €€€€€ (Informationsvorsprung)

### Der Prompt:
```
"Ich habe 5 Analyst-Reports zu Tesla hochgeladen (Goldman, JPM, Morgan Stanley, UBS, Barclays).
1. Was ist der Konsens-View (Bull/Bear/Neutral)?
2. Wo unterscheiden sich die Analysten am meisten?
3. Welche Annahmen treffen die Bulls, die die Bears nicht teilen?
4. Was ist das durchschnittliche Price Target und die Range?
5. Erstelle eine Tabelle: Analyst | Rating | PT | Key Thesis"
```

### Warum wertvoll:
- 5 Reports lesen = 3+ Stunden
- Synthese + Vergleich = echtes Alpha
- Identifiziert Consensus vs. Contrarian Views

### Was dafür nötig ist:
- [ ] Document Upload & Processing
- [ ] RAG System
- [ ] Multi-Document Synthesis
- [ ] Strukturierte Extraktion (Ratings, PTs)
- [ ] Comparison Logic

## PROMPT 9: Anomalie Detection
**Zielgruppe:** Quant, Risk Manager
**Business Value:** €€€€ (Früherkennung)

### Der Prompt:
```
"Analysiere alle meine Positionen auf Anomalien:
1. Ungewöhnliches Volumen (>2x Durchschnitt der letzten 30 Tage)
2. Preis-Bewegung ohne News
3. Abweichung von Sektor-Performance (Stock down, Sector up)
4. Ungewöhnliche Korrelationsbrüche vs. historisch

Zeige nur Positionen die mindestens eine Anomalie haben."
```

### Warum wertvoll:
- Anomalien = oft Vorboten von größeren Moves
- Manuell nicht skalierbar bei 50+ Positionen
- Quantitativer Ansatz = objektiv, wiederholbar

### Was dafür nötig ist:
- [ ] Statistische Anomalie-Detection
- [ ] Sektor-Daten
- [ ] Korrelationsberechnung
- [ ] News-Check (um "ohne News" zu verifizieren)
