### 🕵️ 3. The "Ghost Code" Anomaly

This is the current blocker. We have verified that the code in your editor (`nodes.py`) contains the fix `period=period`. However, the **Execution Logs** prove that this code is **not running**.

**The Evidence (Smoking Gun):**

1. **Log Line A:** `... 751 Zeilen in daily_prices` (This is the **3-Year** fetch we requested).
2. **Log Line B:** `... 1254 Zeilen in daily_prices` (This is a **5-Year** fetch).

**Why this proves the bug:**
The only reason the system would fetch 5 years of data immediately after fetching 3 years is if `calculate_covariance_tool` was called **without** the `period` argument (defaulting to 5Y).

**Conclusion:**
Your Python environment (`python demos/langgraph_demo.py`) is loading a **stale version** of `src/agents/nodes.py`, likely due to:

1. A lingering `.pyc` (bytecode) cache.
2. The file being saved in a different location than where Python is looking.
3. An IDE sync issue.

We stopped before implementing a "Safety Net" (fake data) because it would mask this root cause. We are now ready to perform the "Deep Fix" to force Python to see the new code.
